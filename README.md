# 票务自助机 · 纸卷补给与退款核验平台

模拟票务自助机运营:管理终端、纸卷批次、票据号段、收款订单、故障工单、
补给路线和退款凭证。票务订单与金额均为模拟数据,支付与出票由**进程内模拟
适配器**完成,设备回执写**本地文件**,业务状态保存在 **SQLite**。

## 单条命令启动

```bash
./run.sh            # 首次自动生成演示数据并启动 http://localhost:8000
./run.sh --reset    # 清空 data/ 重建演示数据后启动
./run.sh seed       # 仅重建演示数据(出票/卡纸/重复出票/退款超时/倒装/离线)
./run.sh test       # 运行 18 个测试
PORT=8123 ./run.sh  # 指定端口
```

仅依赖 Python 3.10+ 标准库,无需安装任何第三方包。

| TVM02 | 号段用尽 → 缺纸停车(有一笔扣款未出票入复核) |
| TVM03 | 卡纸 → 扣款成功未出票,**票号不跳号** |
| TVM04 | 打印机重打同号票 → 重复出票停车入复核 |
| TVM05 | 设备离线,2 条事件写入本地暂存队列,恢复后补传 |

扫码开柜领取补给任务、双人抢单、换卷并留存前后计数器照片、人工补票、
财务批准/驳回退款。

## 核心业务规则

- **号段连续**:票号由平台按号段连续分配;卡纸、断纸、倒装等打印失败不消耗
  票号;号段用尽立即停车,不允许跳到下一卷继续打印。
- **订单幂等**:相同幂等键重放返回原订单,支付适配器与出票流程均只执行一次。
- **并发扣减**:`BEGIN IMMEDIATE` 事务 + 条件更新,多线程同时购票不超卖、
  票号不重复。
- **补给流程**:必须扫码(扫码凭证与任务匹配)才能开柜;两名补给员同时领取
  同一任务时只保留一个锁定者;换卷前后计数器读数都生成照片存档;
  非锁定者不能完成任务。
- **复核队列(五类)**:扣款成功未出票、重复出票、退款超时、纸卷倒装、
  设备离线,各自独立入队并可核销。
- **退款**:一张原订单最多一条退款单(数据库 UNIQUE + 状态双检);
  仅财务可批准出款,主管可驳回,驳回后订单恢复原状态。
- **人工补票**:必须关联故障工单、仅主管可操作,补票回挂工单号并占用
  连续票号。
- **离线补传**:离线期间事件写本地回执文件 + spool 表,恢复在线后按序补传,
  `event_id` 去重,重复同步无副作用。

## 目录结构

```
app/
  config.py      路径与主题色(靛蓝/浅灰/亮黄)
  database.py    SQLite 连接与建表
  adapters.py    进程内支付网关、打印机模拟;回执文件
  services.py    领域服务(交易/号段/工单/补给/退款/离线补传)
  demo.py        一键演示数据
  server.py      标准库 HTTP 服务(JSON API + 静态页 + 本地文件)
web/             原生 HTML/CSS/JS 前端(无构建)
tests/           unittest 测试
data/            运行时生成:tvm.db、receipts/、photos/、spool(被 gitignore)
```

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/overview` | 终端/订单/退款/复核/任务汇总 |
| POST | `/api/buy` | 模拟购票(支持 `idem_key` 幂等) |
| POST | `/api/tasks/create` `/claim` `/complete` | 补给任务全流程 |
| POST | `/api/batches/receive` | 纸卷入库(可造倒装卷) |
| POST | `/api/terminals/offline` `/online` | 离线 / 恢复并补传 |
| POST | `/api/spool` `/api/sync` | 离线事件暂存 / 补传 |
| POST | `/api/refunds/apply` `/decide` | 退款申请 / 财务审批 |
| POST | `/api/work-orders/manual-issue` `/resolve` | 人工补票 / 工单结案 |
| GET | `/api/evidence?order_no=` | 纵向证据链:原订单→回执→处理动作 |
| GET | `/files/...` | 本地回执、计数器照片文件 |
